# Sistema de Médias
Sistema Java que permite calcular as médias aritmética e ponderada de provas de alunos específicos.

# ⚒️Funcionalidades⚒️
- O sistema imprime os resultados das médias aritmética e ponderada de cada aluno, de acordo com as notas digitadas.
